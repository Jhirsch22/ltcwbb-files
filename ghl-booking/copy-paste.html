Copy & paste code blocks

Two Custom Code elements, one above the calendar and one below it. Tap a button to copy the whole block, then paste it into GHL.

  1. In the GHL page builder, add a Code element (Custom HTML/Javascript) where the block goes.
  2. Click Open Code Editor, then select everything already in it and delete it.
  3. Tap the Copy button below, paste into the editor, and click Save.
  4. Optional: set the calendar element's ID to calendar-section. If you skip this, the bottom button still scrolls to the "Pick a time" line right above the calendar.
